# Git CI/CD Course 🚀

A simple React "Hello World!" application demonstrating Git workflows and CI/CD pipelines with GitHub Actions.

## Overview

This project is designed as a training tool to teach:
- ✅ Git fundamentals (commits, branches, merging)
- ✅ Remote repositories (clone, push, pull)
- ✅ CI/CD pipelines (build, test, deploy)
- ✅ GitHub Actions workflows
- ✅ Team collaboration with branches and pull requests

## Quick Start

### Prerequisites
- Node.js 18+ installed
- Git installed
- GitHub account

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/git-cicd-demo.git
cd git-cicd-demo

# Install dependencies
npm install

# Start development server
npm run dev
